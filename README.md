# games — сборник прототипов (рабочее название)

> Черновик. Разделы с пометкой **TBD** ещё обсуждаются.

Курс «Геймдизайн и проектирование игр», ШРВ ИТМО, магистратура «Технологии разработки компьютерных игр», 3 семестр.
Формат курса: один прототип игры в неделю. Использование нейросетей приветствуется.
Разработка: один человек.

## Идея

Не набор разрозненных прототипов, а одна большая игра, в которую каждый недельный прототип встраивается как отдельная мини-игра. Сеттинг и нарратив сознательно не фиксируются заранее — они вырастут из того, какие прототипы получатся.

## Принципы

1. **Каждый прототип самодостаточен.** Его можно запустить и сдать отдельно от общей игры.
2. **Единый интерфейс мини-игры.** Мини-игра сообщает хабу о старте, победе/поражении и награде — больше хаб о ней ничего не знает.
3. **Минимум графики.** Примитивы и минимальная анимация; простые готовые ассеты — только если найдутся. Стиль строится вокруг ограничений, а не вопреки им.
4. **Неделя = законченный цикл.** Идея → прототип → плейтест → короткие выводы.

## Технологии

- Движок: Godot 4.7 (Steam-версия)
- Язык: GDScript
- Вид: 2D, паззлы собираются из интерфейсных нод (Control, ColorRect, Panel), анимация через Tween — TBD, подтвердить
- Контроль версий: git, тег на каждую сдачу (`week-01`, `week-02`, …)

## Работа с нейросетями

Для каждого прототипа фиксируется, что сделано с помощью нейросети (идеи, код, тексты, звук) и что пришлось переделывать руками.

## Журнал

- Создана папка проекта, черновик README.

- Неделя 1: выбрана механика «Шестерёнки и засовы» (рассматривались также отмычка, стук, следы на кнопках, говорящий замок).
